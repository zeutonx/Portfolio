LSTM-Driven Portfolio Optimization on NEPSE using Differential Evolution

Nov 2025 – May 2026

Undergraduate thesis

  • Formulated a mixed-integer nonlinear portfolio optimization problem under real-world market constraints and solved it with Differential Evolution, using a custom decode-and-repair operator to keep integer-lot solutions feasible.
  • Combined sector-level LSTM networks with attention for return signals, Ledoit–Wolf shrinkage for covariance estimation, and a penalty-augmented Sharpe ratio objective; ran a systematic sensitivity analysis over the key hyperparameters.

NEPSE-Data: An Open Dataset of the Nepal Stock Exchange

Nov 2026 – present

Open-source project · Code on GitHub · Dataset on Kaggle

  • Built a Python scraper and command-line tool that collects daily prices, full price histories, floorsheets, company fundamentals, dividends, right issues and mergers for every listed NEPSE company, plus 18 market indices since 1997 and Nepal Rastra Bank exchange rates since 2000.
  • Computed bonus- and right-adjusted prices so returns are comparable across book-close dates, and documented quirks in the source data such as duplicate dates and inconsistent dividend totals.
  • Automated the pipeline with GitHub Actions: tests and a data update run daily, and a new version of the dataset is published to Kaggle every two weeks.

Image Compression Using Singular Value Decomposition

May 2025 – Jul 2025

Mathematics seminar project

  • Applied truncated SVD to lossy greyscale image compression, grounded in the Eckart–Young–Mirsky theorem, and verified its error formula numerically.
  • Built a Python (NumPy) compression module and command-line tool with unit tests, choosing the rank by energy retained and PSNR. A 360×360 image is stored with 9× fewer values at 33.5 dB.
  • Analysed when the method fails (random noise vs. structured patterns) and compared it with JPEG.

Physics-Informed Neural Networks vs. Finite Differences for the Heat Equation

Dec 2024 – Apr 2025

Independent project

  • Benchmarked PINNs against explicit, implicit and Crank–Nicolson finite-difference schemes for the 1D, 2D and 3D heat equations, comparing accuracy, runtime and memory under coarse discretization.
  • Trained PINNs with adaptive GradNorm loss weighting, Latin Hypercube Sampling and Adam/L-BFGS. Finite differences were more accurate; PINNs were faster in 3D.
